Speedup trend: does it scale?

MinIO decreases (local disk), cloud backends increase with data size

Key insight: Speedups are in the 5–20× range across all backends. MinIO decreases with size (local disk, per-file overhead adds up). Cloud backends (Azure/AWS) show 6–16× range — network I/O dominates and Parquet's smaller footprint consistently wins at scale.
